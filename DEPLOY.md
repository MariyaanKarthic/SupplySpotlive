# Deploying SupplySpot (free tier)

- **Database:** Neon Postgres (free)
- **Backend API + frontend:** Render, from `render.yaml` (free web service + free static site)
- Optional: frontend on Vercel instead (`Supplyspot_frontend/vercel.json`)

Local development is unchanged: with `DB_CLIENT=sqlite3` in `Supplyspot_Backend/.env` and no `DATABASE_URL`, the backend still uses `dev.sqlite3`.

## 1. Create the database (Neon)

1. Sign in at https://console.neon.tech and create a project (any name, nearest region).
2. On the project dashboard click **Connect** and copy the connection string. It looks like
   `postgresql://neondb_owner:xxxx@ep-xxxx.region.aws.neon.tech/neondb?sslmode=require`

## 2. Load your current data into Neon

From `Supplyspot_Backend` on your PC (PowerShell):

```powershell
$env:DATABASE_URL="<paste the Neon connection string>"
npx knex migrate:latest
npm run db:copy-sqlite
Remove-Item Env:DATABASE_URL
```

This creates the tables and copies everything in `dev.sqlite3` (users, vendors, PRs, RFQs, POs, shipments, invoices, compliance) into Neon. Re-running it replaces the Neon data with a fresh copy.

## 3. Push the code to GitHub

Commit and push these changes so Render can build from the repository.

## 4. Deploy on Render

1. Sign in at https://dashboard.render.com with GitHub.
2. **New → Blueprint**, pick the SupplySpot repository, and confirm.
3. When asked, fill in:
   - `DATABASE_URL`: the Neon connection string
   - `ANTHROPIC_API_KEY`: your Claude API key (leave blank to turn AI features off)
4. Click **Apply**. Render creates `supplyspot-api` (backend) and `supplyspot-web` (frontend).
5. When both are live, open the `supplyspot-web` URL and log in with your usual account.

If Render gives the API a URL other than `https://supplyspot-api.onrender.com`, open `supplyspot-web → Environment`, set `VITE_API_BASE_URL` to `<api url>/api/v1`, and redeploy the site.

## Good to know

- The free Render API sleeps after 15 minutes without traffic; the first request after that takes about a minute.
- Database migrations run automatically every time the API starts (`npm run start:prod`).
- Uploaded files are stored on the server disk, which Render clears on each deploy.
- JWT secrets are generated by Render; changing them logs everyone out.

## Frontend on Vercel instead (optional)

Import the repository at https://vercel.com/new, set **Root Directory** to `Supplyspot_frontend`, add the environment variable `VITE_API_BASE_URL=<api url>/api/v1`, and deploy. `vercel.json` already sets the build output (`build/`) and page routing.
